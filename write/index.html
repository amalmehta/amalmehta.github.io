This page edits amalmehta.com’s Writings. It needs a GitHub token that can write to the site’s repository.

Making a token

On GitHub: Settings › Developer settings › Fine-grained personal access tokens › Generate new token. Repository access: only amalmehta/amalmehta.github.io. Permissions: Contents: Read and write, nothing else. Pick an expiry.

Without “Remember”, the token is forgotten when you close the tab.
