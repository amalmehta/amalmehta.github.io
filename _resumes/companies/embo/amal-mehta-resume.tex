Research engineer in reinforcement learning, with four years in industry and deep learning research since 2020. I've taken a PPO policy from simulation onto a real Unitree Go1, studied how rewards are learned from preferences and demonstrations and how agents exploit them, and built RL systems that improve against real-world feedback. I implement each method myself and test it hard: held-out evals, several seeds, and a prediction written down before each run.

\section*{Experience}

\role{Independent RL \& Robotics Research}{Sept 2025 -- Present}{Self-directed projects, each with public code and a write-up; details at \href{https://amalmehta.com/}{amalmehta.com}}{San Francisco Bay Area}
\begin{itemize}
\item \href{https://amalmehta.com/RewardModeling/}{\textbf{Reward modeling:}} learned rewards from pairwise preferences (Bradley--Terry) and demonstrations (MaxEnt IRL) across five reward shapes, 10 seeds and 1--1,000 labels; hypotheses fixed before the run. EPIC distance predicted downstream policy regret better than raw reward correlation (Spearman 0.61 vs.\ 0.54; 0.46 vs.\ 0.05 on shaped rewards).
\item \href{https://amalmehta.com/long_term_horizon_planning/}{\textbf{Reward hacking (toy code repair):}} GRPO on visible tests raised pass rate 35\%\,$\to$\,58\% while true correctness fell 31\%\,$\to$\,2\%, as the agent deleted 98\% of untested branches; choosing which episodes to audit held false success to 4\% vs.\ 24\% for random audits at the same 10\% budget.
\item \href{https://amalmehta.com/DroneAutonomy/}{\textbf{Quadrotor adaptation:}} batched simulator modelled on a Holybro X500 V2 (500\,Hz), randomizing payload, motor wear, drag, wind and latency; benchmarked domain-randomized PPO and seven meta-learning methods; a learned residual cut held-out tracking error to 7.3\,cm vs.\ 14.0\,cm for tuned L1 adaptive control.
\item \href{https://amalmehta.com/RLInitStability/}{\textbf{RL training dynamics:}} reviewed 68 papers on how initialization and network health shape deep RL stability; built a browser lab that trains PPO under four init schemes, tracking entropy, gradient norm and dormant units.
\item \href{https://github.com/amalmehta/PostTrainingLab}{\textbf{Post-training a policy:}} SFT then GRPO on a small transformer policy; over 3 seeds GRPO lifted held-out success from 70\% to 80\% (DPO: 81\%), where RL from scratch failed.
\end{itemize}

\role{Deep RL Researcher}{Aug 2023 -- Mar 2024}{Hybrid Robotics Lab, UC Berkeley --- adv.\ Prof.\ Koushil Sreenath}{Berkeley, CA}
\begin{itemize}
\item Trained a single multi-stage PPO policy in IsaacGym and ran it on a real Unitree Go1 quadruped to track, approach and kick a soccer ball at a target, replacing the multi-policy hierarchical framework of prior work; $\sim$60\% kicking accuracy on hardware.
\item Designed the three-stage reward and CPG-based gait tracking; prototyped RLPD (SAC mixing offline prior data with online replay) to fine-tune the policy on real robot data.
\end{itemize}

\role{Deep Learning Scientist}{Sept 2021 -- Aug 2025}{PhysicsAI (DARPA-funded)}{Pacifica, CA (remote)}
\begin{itemize}
\item Built a closed RL loop for drone perception: policies (TD3, PPO, DDPG) set a synthetic image generator's parameters, a detector trained on its images, and the detector's accuracy on real drone imagery was the reward.
\item Built the PEARL meta-RL codebase (probabilistic latent task embeddings inferred from off-policy experience, over TD3) for a fighter-jet simulation, so an agent adapts to a new task in a few tries; ran its multi-week GPU training.
\item Implemented domain adaptation from scratch to hold detector accuracy with few real labels (10--15\,GB, mostly synthetic), and built and benchmarked the GAN pipelines (DCGAN, InfoGAN, FineGAN) that generated its training data.
\end{itemize}
